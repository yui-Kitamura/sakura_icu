# Windows ICU による単語移動

「設定」→「共通設定」→「全般」の「単語移動にWindows ICUを使う」をオンにすると、既存の Ctrl＋←／→ で日本語の単語境界を移動できます。設定は再起動後も保持されます。チェックを外すと従来方式に戻ります。初期値と、設定項目のない既存の `sakura.ini` では従来方式が使われます。

## ビルドと導入

1. サブモジュールを含めて取得します。既存のチェックアウトでは `git submodule update --init --recursive` を実行します。
2. [ビルド方法](build.md) に従って Visual Studio と依存ツールを用意し、リポジトリ直下で `build-sln.bat x64 Debug` を実行します。
3. `x64\Debug\sakura.exe` を起動します。別フォルダーで試す場合は、同じビルドの DLL も一緒にコピーしてください。普段の設定を引き継ぐ場合は、元のエディタを終了してから `sakura.ini` をコピーします。

Windows 10 バージョン 1903 以降および Windows 11 のシステム ICU（`icu.dll`）を使います。ICU や辞書の追加導入は不要です。DLL や必要な関数が見つからない場合は従来方式で移動します。[Windows の ICU に関する Microsoft の資料](https://learn.microsoft.com/ja-jp/windows/win32/intl/international-components-for-unicode--icu-)

## 着地点

- 現在編集中の論理行を、折り返し位置に関係なく日本語ロケールで分割します。各キー入力で移動方向の次の境界に止まります。
- 行内の空白やタブから始まる境界を飛ばし、行頭と行末では止まります。`:` と `=` の前後も境界候補です。絵文字や結合文字の途中の位置は飛ばします。
- 行末から右に進むと次の論理行の先頭へ、行頭から左へ進むと前の論理行の末尾へ移動します。空行や末尾改行直後の空の位置にも止まり、文書の先頭と末尾ではそれ以上進みません。
- ICU 方式では独自の着地点を使います。「単語の両端に止まる」の設定は従来方式に適用されます。Ctrl＋Shift＋←／→ による選択拡張、単語選択と検索は従来どおりです。

Windows が提供する ICU のバージョンや辞書によって、地名などの着地点は変わることがあります。次の例では `|` が着地点です。左に移動すると逆順になります。

```text
|name|=|山梨|県|中央|市|
|addr|:|full|=|神奈川|県|足柄下|郡|箱根|町|仙石原|1285|
```

## 検収手順

1. 上記の例を新規文書に入力し、保存前の状態で Ctrl＋←／→ の着地点を確認します。ウィンドウ幅で折り返した状態でも同じ箇所に止まります。
2. 行頭や行末に半角空白を置き、行中にタブ、全角空白、空行、結合文字の `é`、ZWJ を含む絵文字の `👩‍💻` を入れて、両方向に移動します。末尾改行のある場合とない場合をそれぞれ確認します。
3. 地名の行を複数並べ、左右それぞれで Ctrl＋矢印を長押しして移動を確認します。
4. ICU をオンにして再起動し、オンのままであることを確認します。オフに戻して再起動し、従来の着地点に戻ることを確認します。

### 動作確認環境

Windows 11 x64（OS ビルド 26300、システム ICU 72.1）、Visual Studio 2022 の x64 Debug ビルドで確認しました。

- 上記 2 行を左右に移動し、表示された着地点と行またぎを照合しました。ウィンドウ幅で折り返した場合も論理行内の着地点が一致しました。
- 保存前に入力した `name=山梨県中央市` でも同じ着地点に止まりました。設定項目がない状態での従来方式、オン・オフそれぞれの再起動後の保持、Ctrl＋Shift＋←／→ の従来の選択範囲を確認しました。
- 半角空白、タブ、全角空白、空行、結合文字、ZWJ を含む絵文字、末尾改行の有無を左右で確認しました。末尾改行直後の位置から前の行へ戻れることも確認しました。
- Windows のキー入力で左右それぞれ 120 回分のリピートを送り、文書の端まで到達することを確認しました。物理キーの長押しと、ICU を利用できない Windows での実機確認は検収時の確認項目です。
